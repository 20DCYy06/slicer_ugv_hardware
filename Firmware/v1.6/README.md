# v1.6 C30D 后轮左右归属

替换板 `5CF0016377` 的 A/B/C/D 分别为左后、右后、右前、左前。手推时，修改轮位前轮速推导角速度与 IMU 的相关系数为 −0.2049，按实际轮位复算后为 0.9864。固件按此轮位分配转向目标，RTK 与无 RTK 的编码器里程计使用相同轮位。前后极性、PB14、1.0 m/s 目标和 982‰ 闭环上限沿用 v1.5。

从仓库根运行 `./Hardware/build.sh v1.6`。确认 Motor OFF、物理断开 12 V、仅 USB 且底盘串口空闲后，执行 `python3 -s Hardware/Flashing/flash_v1_6_verified.py --power-off-confirmed`。脚本要求当前扇区 0 匹配已验证的 v1.5 或同一 v1.6，在双备份后只擦写扇区 0，校验整片及选项字节。可用 `python3 -s Hardware/zero_check.py` 做断动力验收。

B 路曾在直行手推时丢失有效计数。现场处理接线并确认断动力直推四轮均持续有反馈后，再做架空的低档前进、后退与左右转向验收。运行导航时使用 v1.6 配套 overlay。回退需在断动力条件下用写前双备份恢复扇区 0，核对整片与选项字节，并切回 v1.5 overlay。
