# 直行偏移只读测量

```bash
cd /home/potato/Slicer_Workspace2
./Test/run_feedback_check.sh
```

先退出WASD/手柄，Motor OFF；不用启动导航，也不需要开启X11。程序绝不发送串口数据，不清故障、不解锁、不启停电机。

1. 启动后静置2~3秒，保持默认S静止阶段。
2. 按F（不用回车），沿你定义的车头方向慢推30~50cm，过程中尽量不转弯；停止后按S。不要在F阶段推回。
3. 按L，从上方看逆时针慢转车身约30~60度，车轮接地滚动；停止后按S。
4. 按R，顺时针慢转约30~60度；停止后按S。
5. 按Q结束，复制控制台最后SUMMARY整段发回。原始JSONL和汇总JSON在Test/logs/。

如果脚本提示Motor ON，请将物理Motor拨OFF再运行；不能用推车测量去代替电机运行测试。初期最多采集120秒，可加`--duration 180`。没有交互终端时可分段运行`--phase forward --duration 15`、`--phase left --duration 15`；交互方式优先，便于得到完整方向判断。

分析比较向前推车时各轮编码器方向、手动左右转时IMU符号及当前轮位推导角速度与IMU的相关性。不自动改动任何标定或固件。手推数据可判断反馈坐标是否矛盾，但不能单独验证电机输出极性、地面闭环性能或PID调参结果。
