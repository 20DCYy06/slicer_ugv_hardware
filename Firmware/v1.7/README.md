# C30D v1.7 导航通信锁存恢复

在 v1.6 的替换板和轮位配置上增加通信故障恢复。导航驱动在当前 SLC2 会话启用指令看门狗锁存。串口错误、导航速度指令超时和测试锁存可以在 Motor ON、动力接通时清除。固件要求控制周期正常、IMU 有效且四轮连续 250 ms 处于零 PWM、低于静止阈值的状态。混有编码器、堵转、方向错误或控制周期故障时保持锁存。清锁时固件清除速度目标和控制积分，下一条新的闭环命令才能出力。

协议沿用 SLC2 帧和 0x90/0x93 长度，两帧共享采样时标。0x19 载荷为当前会话 nonce 和操作码。操作码 0 清除符合条件的通信锁存，1 在导航会话中立即停车并产生测试锁存，2 为当前导航会话启用指令超时锁存。0x93 的状态低字节 bit 4 确认会话已启用指令超时锁存，bit 6 公布恢复能力，bit 7 公布清锁条件。高字节 bit 4 表示导航速度指令超时，bit 5 表示测试锁存。

操作入口和现场测试见 [整车操作手册](https://github.com/20DCYy06/slicer-ugv/blob/main/docs/OPERATIONS.md#底盘通信锁存恢复与测试)。烧录要求 Motor OFF、物理断开 12 V、仅 USB 供电和串口空闲。使用 v1.7 校验烧录器核对 v1.6 基线、双备份及全片读回。需要回退时用烧录前同一板的双备份恢复 sector 0，并切回 v1.6 的 ROS 安装。
