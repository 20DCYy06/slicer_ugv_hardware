# v1.5 C30D 替换板固件

基于 v1.4 PB14。A/B 两个后轮的 PWM 和编码器极性同时反转，默认 A/B/C/D 的 PWM 极性为 `[-1, 1, -1, -1]`，编码器极性为 `[-1, 1, 1, -1]`。配套上位机握手使用同一组极性。固件接受最高 1.0 m/s 的车体和单轮速度目标，四轮转弯仍按比例限幅。

闭环 PWM 的配置上限为 982‰，定时器周期 1600，实际限制到 1571 ticks。0x85 返回配置值和实际 tick 上限。独立开环 PWM 的 750‰、500 ms 看门狗、失速和反向保护、PB14、IMU 和 PI/PID 沿用。1.0 m/s 是目标限制，负载下实际速度需要现场测量。

从仓库根运行 `./Hardware/build.sh v1.5`。对已验证的 v1.4 替换板，确认 Motor OFF、物理断开 12 V、仅 USB 供电且串口空闲，再运行 `python3 -s Hardware/Flashing/flash_v1_5_verified.py --power-off-confirmed`。安装前双读原 Flash，仅擦写扇区 0，写后校验整片和选项字节。烧录后可以运行 `python3 -s Hardware/zero_check.py`。

独立遥控和两套 ROS 导航使用 v1.5 配套配置。导航仍以各自规划器和 Guard 的速度为准。请使用本版本重新生成并构建 ROS 安装。回退固件时，在同样的断动力条件下使用本次写前双备份恢复扇区 0，核对整片和选项字节，然后切换回对应 v1.4 的上位机配置与安装。
